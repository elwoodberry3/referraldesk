# referraldesk
Referral capture, attribution &amp; payout tracking for car dealerships. Logs referrals at the desk, credits the referrer instantly, tracks $200 payouts New→Sold→Paid on a live ledger. Next.js 14, Vercel, n8n, HubSpot. Config-driven: one file re-skins per dealership. Demo-mode fallback runs clickable with zero credentials. IAS Build 020.
